# CC5 Workflow Simulator - Design canvas seat

Live canvas (Design artifact type): https://claude.ai/artifact/2utL2vymWfe1hVrStKhR1Z ("CC5 Workflow Simulator"), created 2026-10-09 in the cc5-codify B3 stage. Design system: Griotwave (installed as project/ds/griotwave: styles.css, colors_and_type.css, 5 fonts; the system serves no tokens.json, so the Theme menu shows hex).

34 artboards (16 desktop + mobile pairs plus the order-of-operations flow pair):
- Flow: Main (desktop, entry) + Flow-mobile: Headshot 3 -> CC5 morphs + HD / Extended Plus -> Edit Spring -> iClone 8 bake -> FBX preset -> Blender CC/iC add-on -> Blender bake -> GLB -> R3F. Each node cites video + timestamp + frame. GLB and R3F are dashed: UNPROVEN IN CORPUS (OA3 b2-b4).
- CC5: Headshot 3, Modify / Morph, Facial Profile Editor, Digital Human Eye shader, Export to Blender.
- iClone 8: Data Link, Timeline, Face Key (spoken evidence only), Export FBX dialog.
- Blender: CC/iC Create + Pipeline add-on, Spring Rig, Sculpting, Shader Editor, Timeline, glTF / GLB export (EXTERNAL).
- R3F scene (EXTERNAL: gltfjsx + R3F / drei docs).

Provenance: corpus labels are copied verbatim from boards-manifest.json, which is GENERATED by build-boards-manifest.py from Cinopsis cc5-steps.json @7dccd5a, with the Atlas re-tag and app_raw kept. External labels come from .prism/shared/research/2026-10-08-cc5-gap-board-labels-external.md. The chrome is SIMULATED, with no vendor logos or wordmarks. Boards with more controls than fit carry a "+N more controls in boards-manifest.json" footer.
