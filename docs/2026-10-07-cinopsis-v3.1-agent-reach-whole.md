## Seams worth knowing

- **R9 - state in the data dir.** `reach.paths.reach_home()` (default `data/reach/`, override `CINOPSIS_REACH_HOME`)
  stands in for `home_dir()` at exactly the write sites: `Config.CONFIG_DIR`, the xfetch / bird session syncs, the
  xhs cookie export and the uninstaller's targets. Upstream's home-relative layout is kept inside it.
- **R10 - network probes gated.** `reach.channels.network_probe_allowed()`; closed by default, opened "once" by
  `doctor --live`. bilibili / v2ex / xueqiu each send one request then.
- **No browser by default.** boss's DevTools checks need `CINOPSIS_REACH_BROWSER_PROBES=1`.
- **Registry order.** `reach/__init__.py` loads the registry eagerly, standing in for upstream's
  `agent_reach.channels` package `__init__`, so a cold `import reach.boss` cannot hit a circular import.
- Upstream UI text is kept verbatim (much of it Chinese); only the blocks v3.0 already translated stay English.
